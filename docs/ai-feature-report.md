# AI 기능 설명 보고서

## 1. 한 줄 요약

이 서비스의 AI는 **투자를 대신 결정하는 로봇이 아니라, 사용자의 포트폴리오와 믿을 수 있는 자료를 읽고 이해하기 쉬운 말로 정리하는 투자 보조 도구**다.

쉽게 비유하면 다음 세 역할을 한 팀으로 묶은 것이다.

- 계산기는 비중, 수익률, 위험도를 정확히 계산한다.
- 사서는 공시와 뉴스에서 관련 자료를 찾아 출처를 붙인다.
- 설명가는 계산 결과와 자료를 쉬운 한국어 문장으로 바꾼다.

중요한 숫자는 AI 모델이 마음대로 계산하지 않는다. 프로그램이 먼저 계산하고, AI는 그 숫자의 의미를 설명한다. 사용자는 결과를 참고할 수 있지만, 최종 투자 판단은 직접 내려야 한다.

## 2. 왜 필요한가

투자 앱에는 숫자와 자료가 많지만, 숫자만 보고 다음 질문에 답하기는 어렵다.

- 내가 특정 종목이나 업종에 너무 많이 투자했는가?
- 오늘 수익이 난 이유는 시장 전체가 올랐기 때문인가, 종목을 잘 골랐기 때문인가?
- 새 주문을 넣으면 내 포트폴리오 위험이 어떻게 달라지는가?
- 최근 공시와 뉴스 중 내 보유 종목에 중요한 것은 무엇인가?
- 내가 처음 이 종목을 산 이유가 아직 유효한가?

AI 기능은 흩어진 숫자와 자료를 모아 이런 질문에 한 번에 답하도록 돕는다.

## 4. 기능별 설명

### 4.1 AI 종목 분석

종목 하나를 일곱 개의 서랍으로 나눠 보여준다.

| 서랍 | 의미 |
| --- | --- |
| 현재 상황 | 지금 이 종목에서 확인되는 핵심 상황 |
| 최근 변화 | 이전과 비교해 달라진 점 |
| 시장이 주목하는 요인 | 시장 참여자가 관심을 두는 내용 |
| 확인된 위험 요인 | 공시와 자료에서 확인되는 위험 |
| 내 포트폴리오 영향 | 이 종목이 내 자산에서 차지하는 비중과 영향 |
| 투자 논지 점검 | 처음 투자한 이유와 현재 자료의 비교 |
| 다음에 확인할 일정 | 앞으로 살펴볼 이벤트와 일정 |

사용자가 보유하지 않은 종목이거나 투자 이유를 기록하지 않았다면 개인화 서랍은 빈 값으로 표시된다. 이것은 오류가 아니라 “현재 사용할 개인 정보가 없다”는 뜻이다.

투자 이유가 있다면 검색된 공시와 뉴스를 “투자 이유를 뒷받침하는 자료”와 “투자 이유를 약화하는 자료”로 나눠 보여준다. 관련이 분명하지 않은 자료는 억지로 어느 쪽에도 넣지 않는다.

다음 일정에는 오늘부터 90일 안에 있는 확정 일정만 날짜순으로 최대 5건을 보여준다. 일정이 확인되지 않았다면 예상 날짜를 만들어 내지 않고 빈 목록으로 둔다.

현재 상황·최근 변화·관심 요인·위험·다음 일정처럼 사용자마다 달라지지 않는
내용은 같은 종목에서 6시간 동안 재사용한다. 쉽게 말해 이미 만든 공용 안내문은
잠시 보관해 다시 쓰는 것이다. 내 포트폴리오 영향과 투자 논지 점검은 사람마다
다르므로 저장된 공용 답을 쓰지 않고 매번 최신 개인 정보로 만든다.

### 4.2 Ask My Portfolio

사용자가 “내 포트폴리오에서 반도체 비중이 얼마나 돼?”처럼 일상적인 말로 질문할 수 있다. AI는 질문에 필요한 계산 도구만 골라 사용한다.

일반 챗봇과 다른 점은 기억에 의존해 대답하지 않는다는 것이다. 보유 정보가 필요하면 보유 정보 도구를, 위험 계산이 필요하면 위험 엔진을 호출한다. 투자 권유나 미래 가격 단정처럼 허용되지 않은 질문은 답하지 않는다.

### 4.3 포트폴리오 진단

포트폴리오가 한 종목이나 한 업종에 몰려 있는지, 가격 움직임이 서로 너무 비슷한지, 변동성이 큰지를 계산한다. 병원 검진에서 여러 수치를 종합해 상태를 설명하는 것과 비슷하다.

위험 등급은 AI의 느낌으로 정하지 않는다. 미리 정해진 계산 규칙으로 결정하고, AI는 그 이유를 문장으로 설명한다.

### 4.4 수익률 원인 분석

전체 수익률을 다음과 같이 나눠 본다.

- 시장 효과: 시장 전체가 움직여 생긴 부분
- 업종 효과: 특정 업종 비중 때문에 생긴 부분
- 종목 선택 효과: 같은 시장 안에서 종목을 고른 결과

예를 들어 수익이 났더라도 시장 전체 상승 덕분인지, 보유 종목 선택이 실제로 도움이 되었는지를 구분할 수 있다. 관련 뉴스나 공시가 있으면 같은 시점의 참고 자료로 연결하지만, 단순히 같은 날 일어났다는 이유만으로 원인이라고 단정하지 않는다.

### 4.5 주문 전 점검

주문을 실제로 실행하기 전에 “실행했다고 가정한 포트폴리오”를 먼저 만든다. 현재 상태와 가상 주문 후 상태를 비교해 집중도, 현금 비중, 변동성 변화 등을 보여준다.

이 기능은 주문을 승인하거나 거절하지 않는다. 자동차 내비게이션이 경로의 위험 구간을 알려주되 운전대를 빼앗지 않는 것과 같다.

### 4.6 데일리 브리핑

보유 여부, 보유 비중, 사건의 중요도를 규칙으로 계산해 오늘 볼 항목을 최대 4개로 줄인다. AI가 중요도를 마음대로 정하지 않고, 정해진 점수로 순서를 만든 뒤 문장만 읽기 쉽게 다듬는다.

중요한 일이 없으면 억지로 내용을 만들지 않고 빈 상태를 반환한다.

### 4.7 AI가 이해한 나

사용자의 투자 성향과 종목을 산 이유를 저장한다. 예를 들어 “배당을 보고 샀다” 또는 “한 업종에 너무 몰리는 것을 피하고 싶다” 같은 내용이다.

사용자가 직접 말한 내용과 AI가 추측한 내용은 구분해 저장한다. AI가 추측한 내용은 사실처럼 단정하지 않고 “이렇게 보이는데 맞나요?”라고 확인해야 한다. 비중과 수익률처럼 금방 바뀌는 숫자는 이 메모장에 저장하지 않는다.

### 4.8 응답 피드백

사용자는 답변마다 좋음 또는 아쉬움을 표시하고, 틀린 숫자·관련 없는 답·오래된 정보·불명확한 설명 같은 이유를 남길 수 있다. 같은 답변을 다시 평가하면 평가가 여러 건 쌓이지 않고 마지막 내용으로 수정된다.

각 답변에는 어떤 프롬프트 버전으로 만들었는지도 함께 기록된다. 운영자는 이전
버전과 새 버전의 만족도, 피드백 참여율, 틀린 숫자 신고 비율을 표로 비교해 실제로
품질이 좋아졌는지 확인할 수 있다.

## 5. AI가 답을 만드는 과정

| 순서 | 하는 일 | 쉬운 설명 |
| --- | --- | --- |
| 1 | 사용자와 요청 확인 | 누구의 어떤 질문인지 확인한다 |
| 2 | 필요한 데이터 조회 | 보유 내역, 가격, 공시, 뉴스를 모은다 |
| 3 | 계산 엔진 실행 | 비중과 위험, 수익 기여도를 계산한다 |
| 4 | 관련 자료 검색 | 질문과 가까운 공시·뉴스를 찾는다 |
| 5 | 문장 생성 | GMS의 `gpt-5.4-mini`가 결과를 한국어로 설명한다 |
| 6 | 숫자와 표현 검사 | 계산하지 않은 숫자나 투자 권유 표현이 없는지 확인한다 |
| 7 | 출처와 기준 시각 첨부 | 어떤 자료를 언제 기준으로 사용했는지 함께 보낸다 |

자료 검색에는 문장의 의미가 비슷한지를 찾는 임베딩 기술을 사용한다. 쉽게 말하면 문장을 “의미 좌표”로 바꿔, 단어가 완전히 같지 않아도 내용이 가까운 자료를 찾는 방식이다. 임베딩은 GMS의 `text-embedding-3-small`을 사용한다.

검색 순서는 의미 유사도만으로 정하지 않는다. 제목에 질문의 핵심 표현이 직접 있는지,
자료가 얼마나 최신인지, DART·ECOS 같은 공식 출처인지도 함께 반영한다. 고정된 검색
평가 질문으로 상위 5개 결과 안에 정답 자료가 들어오는 비율을 계속 검사한다.

| 응답 번호와 피드백 기록 | 문제가 생긴 답변을 다시 찾아 개선하기 어려운 문제 |

## 8. 현재 범위와 제한

- 국내 KOSPI·KOSDAQ 종목만 지원한다.
- 앱 안의 가상 포트폴리오를 사용하며 실계좌와 직접 연결하지 않는다.
- 원화만 다루며 환율과 국가별 노출은 분석하지 않는다.
- 목표주가와 애널리스트 컨센서스는 제공하지 않는다.
- 미래 가격이나 수익을 보장하지 않는다.
- 뉴스는 검색 결과의 제목·요약·원문 링크만 저장하며 언론사 본문을 무단 수집하지 않는다.
- 자료가 부족하면 억지로 답을 만들지 않고 빈 결과나 자료 부족 상태를 표시한다.
- AI 답변은 투자 참고 정보이며 투자 권유가 아니다.

## 9. 기대 효과

사용자는 복잡한 숫자와 자료를 직접 조립하지 않고도 “현재 상태”, “왜 이런 결과가 나왔는지”, “다음 행동이 위험을 어떻게 바꾸는지”를 이해할 수 있다. 개발팀은 모든 답변에 계산 근거, 자료 출처, 기준 시각, 피드백 번호를 남겨 품질 문제를 추적할 수 있다.

결론적으로 이 AI의 목표는 **더 많은 말을 만드는 것**이 아니라 **사용자가 자신의 투자 상태를 더 정확하고 쉽게 이해하도록 돕는 것**이다.
